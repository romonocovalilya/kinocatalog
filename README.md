# KinoCatalog — Каталог фильмов и сериалов с API Кинопоиска

Командный учебный проект по учебной практике УП.01 (72 часа). Веб-приложение для поиска фильмов и сериалов через Kinopoisk API Unofficial, формирования персонального накопительного каталога, ведения личной библиотеки просмотра и публикации рецензий.

## Команда разработки
* **Участник 1 (Frontend & UI/UX):** Ромоносова Лилия — макет приложения, светлая/тёмная тема, каталог с фильтрацией по жанрам, карточка фильма, интерфейс отзывов и личной библиотеки.
* **Участник 2 (Backend & Database):** Ромоносова Елена — проектирование схемы БД Prisma, настройка SQLite (`better-sqlite3`), серверные Route Handlers (`/api/*`), импорт данных с Кинопоиска (`seed.ts`) и панель аналитики администратора.

## Стек технологий
* **Фреймворк:** Next.js 16 (App Router) + React + TypeScript
* **Стилизация:** Tailwind CSS v4 (поддержка светлой и тёмной темы)
* **База данных:** SQLite + Prisma ORM 7 (`@prisma/adapter-better-sqlite3`)
* **Валидация и безопасность:** Zod, bcryptjs, HTTP-only cookie-сессии
* **Внешний API:** Kinopoisk API Unofficial

## Основной функционал
1. **Витрина и персональный каталог (`/`)** — для неавторизованных гостей отображаются популярные фильмы с фильтром по жанрам; для вошедших пользователей работает персональный накопительный каталог и поиск по названию, году и типу.
2. **Карточка фильма (`/movies/[id]`)** — подробное описание, жанры, рейтинг КП, прямая ссылка на Кинопоиск, автоматический импорт рецензий с Кинопоиска и CRUD для пользовательских отзывов (с валидацией Zod).
3. **Личная библиотека (`/library`)** — управление списками «Не просмотрено» и «Просмотрено» (доступно авторизованным пользователям).
4. **Авторизация и роли (`/login`, `/admin`)** — регистрация и вход, разграничение ролей `USER` и `ADMIN`, панель аналитики администратора.

## Инструкция по запуску проекта

1. Клонирование репозитория и переключение на ветку **`develop`**:
   ```bash
   git clone <ссылка_на_репозиторий>
   cd kinocatalog
   git checkout develop
   ```
2. Установить зависимости:
   ```bash
   npm install
   ```
3. Создать файл `.env` на основе `.env.example` и указать ключ `KINOPOISK_API_KEY`:
   ```bash
   cp .env.example .env
   ```
4. Применить схему БД и заполнить базу популярными фильмами и рецензиями с Кинопоиска:
   ```bash
   npx prisma db push
   npx tsx prisma/seed.ts
   ```
5. Запустить сервер разработки:
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)
